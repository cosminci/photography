# Agent context

Start at [AGENTS.md](../AGENTS.md) for task-based context pointers. The [SDD router](skills/sdd/SKILL.md) resolves shared guidance; [local guidance](skills/sdd/local.md) owns repository-specific safety and precedents.

[Workflow registration](workflows.json) selects the product owner and profile. The machine-local `agentic.workflowsPath` Git setting selects the shared checkout; resolved workflow snapshots and task evidence belong in ignored `.agent-work/`.
