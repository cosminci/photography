# Country flags

The country catalog references these PNG assets by lowercase ISO 3166-1 alpha-2 code. Keep all 249 catalog references resolvable; the SQLite catalog seam checks the packaged frontend resources.

Missing country/territory images were obtained from [Flagpedia's public FlagCDN service](https://flagpedia.net/download/api) on 2026-11-05 using `https://flagcdn.com/w2560/{code}.png`. Previously shipped images were preserved unchanged.
